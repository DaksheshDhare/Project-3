# ⏱️ Stopwatch

> A lightweight browser-based stopwatch built with HTML, CSS, and JavaScript.

---

## ✨ What is it?

This project is a simple stopwatch application designed to provide accurate time tracking directly in the browser.

It supports the essential stopwatch operations:

**START → STOP → LAP → RESET**

The project was built to practice JavaScript timing functions, DOM manipulation, and event handling.

---

## 🎛️ Controls

| Action | Description |
|--------|-------------|
| ▶️ **Start** | Starts or resumes the stopwatch |
| ⏸️ **Stop** | Pauses the current timer |
| 🏁 **Lap** | Records the current elapsed time |
| 🔄 **Reset** | Clears the timer and recorded laps |
